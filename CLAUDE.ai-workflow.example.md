# Project Instructions

Use docs/ai as the source of truth for project state.

Start by reading:

- docs/ai/PROJECT_CONTEXT.md
- docs/ai/CURRENT_STATE.md
- docs/ai/NEXT_TASK.md
- docs/ai/DECISIONS.md

Rules:

1. Do not scan the whole repo unless needed.
2. Keep work scoped to NEXT_TASK.md.
3. Do not reopen decisions already recorded in DECISIONS.md unless asked.
4. Put future ideas in docs/ai/IDEAS.md.
5. Put bugs, risks, or technical debt in docs/ai/KNOWN_ISSUES.md.
6. Update docs/ai when project state changes.
7. Keep responses concise and action-oriented.
