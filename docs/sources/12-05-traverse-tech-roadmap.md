# 12-05 Traverse Tech Roadmap

**Date:** 12-05 (year not stated)  **Participants:** Jeff Hammond, Mauricio Melendez
**Aliases (identical files in parent repo Transcripts/):** 12-05 Strategic Roadmap for Traverse Tech Launch and Growth-transcript.txt
**Booking relevance:** High. The first two minutes set the build order with the Sabre/ARC online booking tool first, and discuss who uses that tool.

## Summary for agents
Jeff states the "steps to success" for Traverse Tech: first build an online booking tool linked to Sabre and Traverse's ARC. Use Trace, which pulls Sabre data, in the meantime. Next build Flight Bridge's own CRM to do what Trace does. Then build group and personal portals. Mauricio confirms this order. Mauricio will produce wireframes for Jeff to build from. The online booking tool is for clients, not for Traverse's own agents, because it carries a fee. Mauricio already has clients lined up to use it. The target is everything running within two years. Speaker labels in this transcript are unreliable: almost every line after 00:01:07 is labeled "Mauricio", including lines that are clearly Jeff speaking.
