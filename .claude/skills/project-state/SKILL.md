# Project State Skill

Use this skill when reading, writing, or preserving project state.

Project state lives in:

- docs/ai/PROJECT_CONTEXT.md
- docs/ai/CURRENT_STATE.md
- docs/ai/NEXT_TASK.md
- docs/ai/DECISIONS.md
- docs/ai/COMPLETED_TASKS.md
- docs/ai/IDEAS.md
- docs/ai/KNOWN_ISSUES.md

Rules:

1. Project state files are more important than conversation memory.
2. Summarize project state, not conversation history.
3. Keep files short and actionable.
4. Preserve only information needed for future work.
5. Do not duplicate the same information across multiple files unless necessary.
