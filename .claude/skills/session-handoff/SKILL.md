# Session Handoff Skill

Use this skill before /compact, /clear, or ending a session.

Rules:

1. Preserve project state in docs/ai.
2. Do not preserve irrelevant conversation history.
3. Keep handoff short.
4. Make the next step obvious.
5. Record completed work only when it is actually complete.
6. Recommend /compact when continuing the same task.
7. Recommend /clear when switching tasks.
