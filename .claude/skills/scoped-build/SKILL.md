# Scoped Build Skill

Use this skill when implementing code changes.

Rules:

1. Use docs/ai/NEXT_TASK.md as the source of truth.
2. Stay inside the defined scope.
3. Do not chase unrelated improvements.
4. If the user requests work outside NEXT_TASK.md, clarify whether NEXT_TASK.md should change.
5. If unrelated issues are found, record them in KNOWN_ISSUES.md.
6. If future ideas come up, record them in IDEAS.md.
7. Prefer small, complete changes over large rewrites.
