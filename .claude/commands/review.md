# /review

Review the current work.

Check for:

1. Bugs
2. Missing tests
3. Broken assumptions
4. Scope creep
5. Incomplete implementation
6. Documentation drift
7. Cleanup opportunities
8. Violations of DECISIONS.md

Return:

- Pass/fail summary
- Required fixes
- Optional improvements
- Whether this is ready to checkpoint or finish

Rules:

- Do not implement during review unless explicitly told.
- Keep optional improvements separate from required fixes.
