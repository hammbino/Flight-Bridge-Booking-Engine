# /finish

Close the session before /clear or ending work.

Update:

- docs/ai/CURRENT_STATE.md
- docs/ai/NEXT_TASK.md
- docs/ai/DECISIONS.md
- docs/ai/COMPLETED_TASKS.md
- docs/ai/IDEAS.md
- docs/ai/KNOWN_ISSUES.md

Rules:

1. Record completed work in COMPLETED_TASKS.md.
2. Remove completed items from NEXT_TASK.md.
3. Keep only the next clear task in NEXT_TASK.md.
4. Preserve decisions in DECISIONS.md.
5. Move deferred ideas to IDEAS.md.
6. Move bugs, risks, or technical debt to KNOWN_ISSUES.md.
7. Keep everything concise.
8. Recommend /clear if switching tasks.
9. Recommend /compact if continuing the same task.

End with:

- Completed work
- Remaining work
- Recommended next command: /compact or /clear.
