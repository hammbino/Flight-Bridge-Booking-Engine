# /build

Use docs/ai/NEXT_TASK.md as the source of truth.

Rules:

1. Stay focused on the current objective.
2. Do not expand scope.
3. Do not chase ideas from IDEAS.md unless explicitly told.
4. Make the smallest useful implementation.
5. Update docs when behavior changes.
6. If the requested work is not in NEXT_TASK.md, stop and ask whether to replace NEXT_TASK.md or add the request to IDEAS.md.
7. If unrelated issues are found, add them to KNOWN_ISSUES.md and keep moving.

Before editing files, state:

- What will change
- Files expected to be touched
- Success criteria

After editing files, state:

- What changed
- How to verify
- Whether /review should be run next.
